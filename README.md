# [ SEWER WORLD ] 🐀

> Base de operaciones digital del estudio indie unipersonal operado por **sewer boy**.

Este repositorio contiene el código fuente del hub web de **SEWER WORLD**. No hay frameworks inflados, no hay librerías de terceros complejas. Solo HTML crudo, CSS (con diseño Lo-Fi Chill) y Vanilla JS, escrito desde el subsuelo para documentar el proceso de sobrevivir al Game Dev.

🌍 **Transmisión en vivo:** [sewerboy3.github.io/sewerworld](https://sewerboy3.github.io/sewerworld)

---

## ⚙️ [ ESPECIFICACIONES DEL SISTEMA ]

* **Operario:** sewer boy
* **Motor Principal (Juegos):** Godot Engine 4.x
* **Stack Web:** HTML5, CSS3 (Variables, CSS Grid/Flexbox), Vanilla JS.
* **Paleta Visual:** Lo-Fi Chill (Azul Noche, Menta, Durazno, Lavanda).
* **Tipografía:** VT323 (Google Fonts).

## 📂 [ ARQUITECTURA DEL DIRECTORIO ]

El sitio está diseñado con una estructura estática y responsiva:

- `index.html` -> Terminal principal y manifiesto personal (`/ABOUT`).
- `projects.html` -> Archivo de prototipos, juegos y fracasos documentados (`/PROJECTS`).
- `devlog.html` -> Registros de desarrollo y reflexiones de diseño (`/DEVLOG`).
- `template.html` -> Archivo maestro. Plantilla base para generar nuevas secciones del sistema.
- `sewer-styles.css` -> Motor gráfico de la web.
- `sewer-scripts.js` -> Scripts de animaciones de interfaz (efecto `>>_`).

## 🚀 [ INICIO MANUAL ]

Como este proyecto no utiliza dependencias de servidor ni compiladores mágicos, ejecutarlo en una terminal local es directo:

1. Cloná el repositorio en tu máquina:
   git clone [https://github.com/SewerBoy3/sewerworld.git](https://github.com/SewerBoy3/sewerworld.git
2. Accedé a la carpeta del proyecto.
3. Ejecutá `index.html` en cualquier navegador moderno (se recomienda usar *Live Server* en VSCode para evitar problemas de caché).
